# 🐍 Python Fundamentals

Structured Python practice covering fundamentals to advanced concepts — built through daily hands-on coding, not passive tutorial-watching.

## 💡 Why this repo exists

Most people don't struggle to learn Python because tutorials aren't available — they struggle because watching someone else code isn't the same as knowing how to code yourself.

This repo is my personal, hands-on walkthrough of core Python concepts. Every file represents a concept I implemented myself — real logic, real code, real problem-solving. No copy-pasted snippets, no passive learning.

If you're tired of jumping between hour-long YouTube tutorials and forgetting everything by the next video, this repo is meant to help you learn the same way I did: by writing the code yourself.

## 🚀 How to use this repo

1. Clone the repository:
```bash
   git clone https://github.com/fizzafatima777/python-fundamentals.git
```
2. Open any file in order (start with `FirstProgram.py`).
3. Read through the code, then **don't just read it — run it, break it, and modify it.**
4. Try recreating each concept from scratch before moving to the next file.
